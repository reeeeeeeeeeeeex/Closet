## Dependencies

JavaScript dependencies and their versions are recorded in `package.json` and `pnpm-lock.yaml`. Android dependencies are declared in `android/app/build.gradle`, `android/variables.gradle`, and the Capacitor Android projects. These packages include their own licenses and notices. Preserve those notices when redistributing their code or binaries.

The main application uses React, Next.js, Capacitor, Drizzle ORM, the Model Context Protocol SDK, and other open-source libraries. Their inclusion does not transfer ownership or change their licenses. After installing dependencies, `pnpm licenses list` displays the JavaScript dependency license inventory.

The Android build includes `assets/public/third-party-licenses.md`, generated by Vite from the JavaScript dependencies actually bundled into the app. `assets/public/licenses/` also includes the project license, the shadcn and Capacitor MIT notices, and the Apache 2.0 license used by AndroidX and Kotlin. AndroidX is copyright The Android Open Source Project; Kotlin is copyright JetBrains s.r.o. and Kotlin Programming Language contributors. Preserve any additional notices supplied with these dependencies.
