# 前端原生翻译接口

当前只启用简体中文，没有用自动翻译填充其他语言。

- `messages/zh-CN.json` 是中文来源语言包，覆盖界面、表单、提示、错误、备份进度、网页元数据和无障碍标签。
- `messages/locale.template.json` 是留给人工翻译的空白模板。复制为 `en.json`、`ja.json` 等后，逐条填写即可；模板本身不作为可选语言启用。
- 来源原文作为稳定的 gettext 风格键，译文可以完整改写；不要改键。单品名称、颜色、备注、搭配名称等用户输入不会自动翻译。

新增语言时，在 `core.ts` 导入对应 JSON 并加入 `catalogs`，例如 `"en": en`。界面通过 `useI18n()` 获取 `t`、`locale`、`setLocale`；语言保存在 `closet_locale` Cookie 中，服务端 HTML 的 `lang`、网页元数据和客户端使用同一语言。需要语言切换控件时使用 `setLocale`，并刷新服务端路由更新网页元数据。

翻译保留 `{count}`、`{time}`、`{value1}` 等插值名称，位置可按目标语言调整。动态提示使用完整句子作为翻译单元。可以使用 CLDR 复数形式：

```json
{
  "{count} 条记录": {
    "one": "{count} record",
    "other": "{count} records"
  }
}
```

日期和尺寸数字用 `Intl` 按当前语言显示；ISO 日期、品类标识、鞋码和尺寸的存储格式保持独立。空白或缺失译文回退到中文。原生日期选择器和文件／相机窗口由浏览器与操作系统提供，应用设置 HTML 语言提示，不替换系统界面。

新增前端文案时调用 `t("来源原文")`，事件和备份工具可用 `tr`。`node scripts/i18n-catalog.mjs` 更新来源包和空白模板，保留已有来源译文，不改人工语言包。
