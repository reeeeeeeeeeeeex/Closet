# Android UI v2：减少常驻占用

2026-10-12 根据手机空间反馈调整。主页面去掉 NEW CLOSET 品牌行、头像、大标题、统计副标题和宣传文案，直接展示操作与内容。保留暖白配色、两列照片和四个底部导航。账号仍可在“我的”中切换、新建和改名，以文字显示账号名称。PC 入口保留原布局。

## 页面调整

- 衣橱、搭配：直接从搜索、筛选、分类开始，减少工具栏间距。390×844 生产预览实测搜索顶部约 12 px，照片顶部约 114 px，底部导航约 61 px，无横向溢出。
- 日历：直接从月份切换开始，收紧日期网格和当天记录，去掉常驻快照说明。
- 我的：去掉头像和大块账号面板；账号名称、切换入口、保存状态及三个功能入口使用紧凑行。
- 单品、搭配详情：44 px 左右功能标题栏、240 px 照片预览、紧凑照片操作和固定保存按钮；去掉品牌输入提示、重复说明，保留可展开字段及错误提示。
- 大图：标题和照片序号使用一行，去掉常驻操作说明，收紧缩放和编辑/裁剪/下载工具栏；原图、手势、裁剪另存规则保留。
- 尺码：去掉重复衣橱介绍和卡片外框，双列字段；测量方法移入“使用说明”，输入字段仍有可访问的测量说明。
- 数据与备份：使用紧凑分隔区、文字统计和文件操作；去掉装饰上传框和大块说明卡片，保留导入结果、容量限制、同步状态及冲突内容。
- 穿搭灵感：上下文按需展开，复制按钮可直接使用，保留未连接模型的说明。
