# Android UI v1 预览

本版先确定安卓的视觉与操作方式：暖白底、深色文字、少量灰绿色，照片为主，四个底部导航入口。PC 入口继续使用原布局；安卓和 `/android-preview` 显式选择新布局，共用原来的记录、账号、图片和同步逻辑。

## 生图到实现

使用内置 `image_gen`，在页面实现前分别生成六张参考稿：衣橱、搭配、日历、我的、单品详情、大图查看器。参考稿保存于 `outputs/android-ui-v1/reference/`。另外生成四张衣服演示照片，用于隔离的 UI 验收，未导入正式衣橱，也没有预置进 APK。

设计提示词和流程记录在 `outputs/android-ui-v1/page-prompts.md` 与 `asset-prompts.json`。本版采用暖白 `#f7f5f0`、墨绿黑 `#29362f`、灰绿色辅助色，18 px 页面边距、14–18 px 圆角、至少 44 px 主要触摸目标。

- 衣橱和搭配：照片网格、名称和一行辅助信息；右下角添加；颜色、场合、收起状态和分组入口放入底部面板。
- 日历：月标题居中、左右月份箭头、按实际月份显示五或六周；当天穿搭显示为横向卡片，保留年月跳转及回到今天。
- 我的：账号切换、保存状态、尺码、数据与备份、穿搭灵感。
- 单品详情：全屏编辑，照片和常用字段优先；颜色、版型尺寸、备注可展开；保存按钮固定在底部。
- 大图：暖白背景，保留双指/滚轮缩放、拖动、裁剪另存、原图下载和编辑入口。
- 尺码或灵感页面有草稿时，底部导航先提示保留或放弃；账号切换沿用原来的草稿保护。

## 验收

依照项目约定先执行 `pnpm build`，再执行静态检查、类型检查与 `pnpm test`。浏览器使用 `pnpm start`、4339 端口及 `.test-runtime/android-ui-v1-final/`，截图保存于 `outputs/android-ui-v1/screenshots/`。原有网页、账号、原图、备份和同步测试仍需全部通过。

Android 测试使用已签名 Release APK，以及单独的仪器测试包。新增 `androidNavigationAndDraftProtection` 检查四个导航入口、尺码入口、保留草稿和明确放弃后切换；原有实际相机入口与照片缩放裁剪测试继续用于本版。

演示照片、界面参考稿和浏览器测试资料都属于预览资料。手机安装后显示自己的本地衣橱；同签名覆盖安装保留数据。物理手机和厂商键盘、安全区域仍需真机确认。
